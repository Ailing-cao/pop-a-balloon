# 电控串口通信

已在 `main.py` 接入 `serial_control.py`，运行 `main.py` 即可随识别结果发送。

以下为 `config/user_config.py` 中的默认设置。可通过 `SERIAL_ENABLED`
启用/关闭串口，并通过 `CONTROL_TARGET_LABEL` 修改目标类别名称。

## 默认发送规则

- 一帧有多个检测框时，按 `宽 × 高` 选择面积最大的有效框。
- 最大框标签为 `redballon`：发送一个字节 `0x00`。
- 最大框标签为 `brown`、`blue`、`pink`、`green`、`shallowblue`、`purple` 等其他有效标签：发送一个字节 `0x01`。
- 没有检测框：不发送任何数据，也不重复上一帧结果。
- 每个有目标的画面发送一次；标签连续相同时仍逐帧发送。
- 框面积相同时选择检测结果中的第一个框。

检测框已由主程序按置信度阈值 `0.25` 过滤，框的坐标格式为 `(x, y, w, h)`。

## 默认串口及接线

- 波特率：**115200**。
- 格式：**8N1**（8 数据位、无校验、1 停止位）。
- 串口：**UART1**。
- K230 **IO9 / TX** → 电控 **RX**。
- K230 **GND** → 电控 **GND**。
- **IO10 / RX** 已配置；当前只发送，电控无需接 TX。

串口号及引脚在 `config/user_config.py` 中修改 `UART_ID`、`TX_PIN`、`RX_PIN`；
接线按开发板的 IO 编号，与所填参数保持一致。

## 数据包格式

默认采用单字节二进制协议，不含帧头、帧尾、校验和换行。
电控读取到字节值 `0` 表示红气球，字节值 `1` 表示其他标签。

如果电控需要的是 ASCII 字符 `'0'` / `'1'`，在 `config/user_config.py` 中改成：

```python
CONTROL_TARGET_PACKET = b"0"
CONTROL_OTHER_PACKET = b"1"
```

ASCII 对应字节是 `0x30` / `0x31`，请按电控实际接收协议选择。
若已有固定的包格式，直接将这两个参数改成完整的目标/其他类别数据包。

示例：一个画面同时有面积 1200 的 `redballon` 和面积 3000 的 `blue`，
只发送一次 `0x01`；下一帧无检测框，则不发送。
